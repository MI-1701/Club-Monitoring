**You receive:**

## FAQ

**FR**

**Q : Je n'y connais rien en informatique, c'est grave ?**
R : Non. Vous m'envoyez vos données dans des modèles Excel/CSV fournis,
je m'occupe de tout le reste. Vous recevez un simple lien à ouvrir.

**Q : Mes données sont-elles en sécurité ?**
R : L'application traite les fichiers en mémoire, le temps de la session ;
elle ne les stocke dans aucune base de données. Vous restez l'unique
détenteur de vos données. (Important pour le suivi de jeunes athlètes.)

**Q : Ça marche pour un autre sport que le volley ?**
R : La base oui (charge, bien-être, blessures). Les tests spécifiques
sont pensés pour le volley ; on peut adapter — écrivez-moi avant de
commander.

**Q : Puis-je essayer avant d'acheter ?**
R : Oui — la démo en ligne tourne avec des données fictives. Testez-la,
puis commandez.

**Q : Et si je veux le faire tourner sur mon propre compte ?**
R : C'est possible — précisez-le en commandant, on le met en place.

**EN**

**Q: I'm not technical at all — is that a problem?**
A: No. You send me your data in the provided Excel/CSV templates, I
handle everything else. You get a simple link to open.

**Q: Is my data safe?**
A: The app processes files in memory, for the session only; it stores
nothing in any database. You remain the sole holder of your data.
(Important when monitoring young athletes.)

**Q: Does it work for a sport other than volleyball?**
A: The core does (load, well-being, injuries). The specific tests are
volleyball-focused; we can adapt — message me before ordering.

**Q: Can I try before buying?**
A: Yes — the live demo runs on fictional data. Test it, then order.

**Q: What if I want it on my own account?**
A: Possible — mention it when ordering and we'll set it up.
